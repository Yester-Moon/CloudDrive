# CloudDrive 网盘项目 - 进度分析与开发规划

## 📋 项目概述

CloudDrive 是一个基于 .NET 8 和 C# 12.0 开发的云存储网盘系统，采用领域驱动设计(DDD)架构模式，旨在提供文件上传、下载、分享、存储管理等核心功能。

**技术栈：**
- .NET 8
- C# 12.0
- Entity Framework Core
- ASP.NET Core Identity
- JWT 认证
- MediatR (领域事件)

## 🏗️ 架构设计

项目采用经典的DDD分层架构：

```
CloudDrive
├── CloudDrive.Domain          # 领域层（核心业务逻辑）
├── CloudDrive.Application     # 应用层（用例和业务流程）
├── CloudDrive.Infrastructure  # 基础设施层（数据访问和外部服务）
├── CloudDrive.WebApi          # 表现层（API接口）
└── CloudDrive.Common          # 公共层（通用组件）
```
